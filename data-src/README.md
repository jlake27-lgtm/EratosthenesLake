# Source data

Unmodified copies of two files from the [Stellarium](https://github.com/Stellarium/stellarium) repository
(`data/base_locations.txt`, `data/regions-geoscheme.tab`), licensed GPL-2.0-or-later. The city records in
`base_locations.txt` originate from [GeoNames](https://www.geonames.org/) (CC-BY 4.0).

Run `npm run cities` to regenerate `public/data/cities.json` from these files.
